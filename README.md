# java-movie-precourse
## 기능 목록
### 목표
쉽고 빠르게 영화를 예매할 수 있는 프로그램 구현

<br>

### 상영관 및 상영 시간 배정
- [x] 하나의 영화는 주어진 상영 가능 기간에 하루에도 여러 차례 상영될 수 있음
- [x] 영화의 상영 시간은 영화의 상영 길이와 상영관 운영 시간에 따라 정해짐

<br>

### 영화, 상영 시간 및 좌석 선택
- [ ] **영화 선택**
    - [ ] 상영 중인 영화 정보 제공
    - [x] 선택된 영화의 제목이 올바른지 검증
    - [ ] 여러 영화를 한 번에 예매할 수도 있음
      - [x] 선택된 영화 수가 1개 이상, 전체 영화 수 이하인지 검증
- [ ] **상영 시간 선택**
  - [x] 각 영화의 상영 시간 정보 제공
  - [ ] 선택된 상영 시간이 올바른지 검증
  - [ ] 여러 영화를 한 번에 예매할 수도 있음
    - [x] 선택된 모든 영화의 상영 시간이 선택되었는지 검증
    - [x] 서로 시간이 겹치는 상영인지 검증(시간이 겹치는 상영이면 함께 예매 불가능)
- [ ] **좌석 선택**
  - [x] 좌석 정보 제공
    - [ ] 영화와 상영 시간을 고른 상태인지 검증 
    - [x] 각 좌석은 행(알파벳)과 열(숫자)로 표시 (e.g. A1, C3, E4)
    - [x] 이미 예약된 좌석 구분
  - [x] 이미 예약된 좌석인지 검증

<br>

### 결제
- [ ] **등급별 가격**

    | 등급 |   가격    |
    |:--:|:-------:|
    | S석 | 18,000원 |
    | A석 | 15,000원 |
    | B석 | 12,000원 |

- [ ] **혜택**

  | 혜택 |   조건    |    할인     |  
  |:--:|:-------:|:---------:|
  | 무비데이 | 매월 10일, 20일, 30일에 상영되는 영화 |  10% 할인   |
  | 시간 | 오전 11시 이전 또는 오후 8시 이후에 시작되는 상영 | 2,000원 할인 |
  - [ ] 무비데이, 시간 조건 동시 적용 가능
  - [ ] 혜택 적용 순서
    - [ ] 무비데이 할인 적용
    - [ ] 시간 조건 할인 적용
    - [ ] 사용자는 보유한 포인트 사용 가능, 포인트는 예매 금액에서 직접 차감
    - [ ] 포인트 적용한 뒤 결제 수단에 따른 추가 할인 적용
      - [ ] 신용카드 결제 5% 할인
      - [ ] 현금 결제 2% 할인

<br>

## 구현 전략
- 설계에 충분한 시간을 투자한다.
- 어떤 클래스가 필요한가가 아니라 어떤 객체들이 어떤 메시지를 주고받으며 협력하는가에 대해 고민한다.
- 상태가 아닌 행동에 초점을 맞춘다.(객체의 행동은 객체가 협력에 참여하는 유일한 방법)
- TDD로 구현한다.
- 테스트는 예외 뿐만 아니라 성공 케이스도 작성한다.
